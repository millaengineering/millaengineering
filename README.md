# Hi, I'm Milla 👋

I'm 16, and I'm working toward a career in Formula 1 race engineering. My long-term aim is to become either a performance engineer or a data analyst in Formula One. 

## What I'm building

**[Apex by Milla](https://apexbymilla.com)** is the project I run alongside my IGCSEs. It's an independent technical analysis of every 2026 F1 Grand Prix, written through an engineering lens: tyre strategy, energy management under the new 50/50 power unit regulations, active aerodynamics, and pit wall decision-making.

The site is built in deliberate stages so the depth of analysis visibly grows across the season:

- **Stage 1, Rounds 1-3** (complete). Foundations: race overview, qualifying breakdown, tyre and aero technical analysis.
- **Stage 2, Rounds 4-8** (in progress). Quantitative pace comparison tables, Engineering Question of the Race deep-dives, Race Engineer's View pit-wall verdicts, primary-source citations.
- **Stage 3, Rounds 9-14** (planned). Data visualisations via FastF1, expanded glossary, and component reference graphics.
- **Stage 4, Rounds 15-22** (planned). Cross-race trend analysis, team upgrade tracking, season-long championship context.

## Stack

HTML, CSS, vanilla JavaScript on GitHub Pages. No frameworks, deliberately simple so iteration is fast and I'm learning the fundamentals properly.
